Lo que aprenderemos hoy será a ordenar por múltiples columnas, ya sean dos o más.

<img src="../../Assets/Titles/Things I learned.png"><br>
Esto se logra utilizando:

`df.sor_values(by=[...], ascending=[...], inplace=True)`

El `inplace=True` puede ser reemplazado, construyendo otro dataframe del dataframe con sort values.
